# 2025 大罷免案件地區查詢

這是一個可部署到 GitHub Pages 的純靜態網站。查詢程式在使用者的瀏覽器內執行，不會把選擇傳送到伺服器或儲存。

## 發佈到 GitHub Pages

1. 在 GitHub 建立一個 repository。若希望網址較簡短，可將 repository 命名為 `你的帳號.github.io`；也可以使用一般 repository。
2. 將本資料夾內的 `index.html` 與 `README.md` 上傳到 repository 根目錄。
3. 在 repository 開啟 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/ (root)`，按 **Save**。
5. 等待 GitHub Pages 部署完成，再從 **Settings → Pages** 複製網站網址分享。

## 更新網站

修改 `index.html` 後 commit 到 `main` 分支，GitHub Pages 會重新部署。
